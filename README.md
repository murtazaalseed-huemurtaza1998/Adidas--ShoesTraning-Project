# Adidas Store Template
قالب متجر احذية Adidas احترافي - HTML CSS JS

## 📸 المعاينة
![Preview](preview.png)
رابط الديمو: [ضع رابط Netlify هنا]

## ✨ المميزات
- **تصميم احترافي Glassmorphism** مع تأثير Blur
- **متجاوب 100%** يعمل على الموبايل والتابلت والديسكتوب
- **تغيير الوان فوري** بضغطة زر
- **سلة مشتريات** تعمل بالـ JavaScript
- **انيميشن احترافي** للحذاء والازرار
- **كود نظيف ومعلق** وسهل التعديل
- **يدعم اللغة العربية RTL**

## 🛠️ التقنيات المستخدمة
- HTML5
- CSS3 + Flexbox
- Vanilla JavaScript
- Google Fonts - Cairo

## 🚀 طريقة التركيب
1.  نزل الملفات
2.  غير الصور في مجلد `img`
3.  غير الاسعار والنصوص من ملف `index.html`
4.  ارفعه على Netlify او اي استضافة مجانية
